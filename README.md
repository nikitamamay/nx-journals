# nx-journals
Скрипты-журналы для NX.

Доступны следующие скрипты:
* `surface_offsets.py` - скрипт для работы с оболочечными моделями при их подготовке перед экспортом в Ansys.
* `components/main.py` - коллекция скриптов с диалогом и иконками для работы с компонентами при моделировании по методологии сверху-вниз.
