# nx-journals
Скрипты-журналы для NX.

Доступны следующие скрипты:
* `nxopen-generate-pyi/main.py` - коллекция скриптов для генерации pyi-файлов для NXOpen с объявлениями модулей, функций, классов, методов с их текстовой документацией и  аннотациями типов.

    Готовые pyi-файлы NXOpen для NX 12 для размещены в репозитории [nx12-nxopen-pyi](https://github.com/nikitamamay/nx12-nxopen-pyi).

* `components/main.py` - коллекция скриптов с диалогом и иконками для работы с компонентами при моделировании по методологии сверху-вниз.

* `surface_offsets.py` - скрипт для работы с оболочечными моделями при их подготовке перед экспортом в Ansys.
